# Connector logos

Each logo only identifies the service a user connects. The files are unmodified. Bean is not made, endorsed or certified by these companies.

| Service | Asset | Source | Terms that allow it |
|---|---|---|---|
| GitHub | `connector-github`: `GitHub_Invertocat_Black.svg`, `GitHub_Invertocat_White.svg` | https://brand.github.com/GitHub_Logos.zip, from https://brand.github.com/foundations/logo | "Use a permitted GitHub logo to inform others that your project integrates with GitHub." Unmodified, less prominent than Bean's own name, no suggestion of endorsement. |
| Dropbox | `connector-dropbox`: `Glyph_128.svg` | Brand partner toolkit, Logos/Dropbox/Glyph, linked from https://brand.dropbox.com/logo | https://docs.dropboxapi.com/dropbox-api/docs/developer-resources/branding-guide: name and logo only to identify or direct a user to a Dropbox integration, approved logos only. |
| Canva | `connector-canva`: `Canva Icon logo.svg` | https://www.canva.dev/assets/connect/Canva-logos.zip | https://canva.dev/docs/connect/guidelines/brand and https://www.canva.dev/docs/mcp/usage-policy/: icon logo below 50 px, at least 8 px of padding, no change of shape or color, no suggestion of endorsement. |
| Linear | `connector-linear`: `logo-dark.svg`, `logo-light.svg` | https://static.linear.app/design-assets/Linear-Brand-Assets.zip, from https://linear.app/brand | https://linear.app/brand: the logomark refers to Linear in tight layouts and logo grids. Unaltered, no implied relationship, not combined with other graphics. |

## Monogram only

| Service | Why |
|---|---|
| Vercel | https://vercel.com/geist/brands asks for written permission (brand@vercel.com) for this use. |
| Atlassian | https://www.atlassian.com/legal/trademark gives logo use to authorized partners and vendors. Others need written approval. |
| monday.com | https://monday.com/p/news/press-kit/ does not say who may use the logo, and forbids the capsule alone. https://developer.monday.com/apps/docs/app-listing-guidelines asks for a license. |
| Notion | The brand guide approves wording and a badge, not the logo in an app. The Notion Trademark Usage Guidelines could not be read. |
| Sentry | https://sentry.io/branding/ offers files but gives no rule for third parties. |
| Granola | Press files exist, with no usage terms. |
